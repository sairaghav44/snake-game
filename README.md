# 🐍 Snake Game

A classic Snake game built with **Python** and **Pygame**. This project started as a hands-on way to learn Python game development, one feature and one bug at a time.

## 🎮 Features

-  Grid-based snake movement
-  Arrow-key controls
-  Random apple spawning on valid grid positions
-  New apples do not spawn on the snake's body
-  Score tracking
-  Snake grows when it eats an apple
-  Prevents immediate direction reversal
-  Self-collision detection
-  Game Over screen with final score
-  Play Again button to restart the game
-  Wall-boundary handling

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/sairaghav44/snake_game_v0.1.git
cd snake_game_v0.1
```

### 2. Install Pygame

Using Python 3.13:

```bash
py -3.13 -m pip install pygame==2.6.1
```

### 3. Run the game

Run the original version:

```bash
py -3.13 snake-game.py
```

Or run version 0.2:

```bash
py -3.13 snake-game_v02.py
```

## 🕹️ Controls

| Key | Action |
|---|---|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |
| Mouse click | Click **Play Again** after Game Over |
